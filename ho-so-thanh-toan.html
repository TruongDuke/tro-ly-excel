Lập hồ sơ thanh toán vận chuyển

Thả file hồ sơ kỳ trước và file số liệu (Google Sheet theo dõi doanh thu tải về, hoặc file khối lượng xe), chọn khách hàng, cung đường, ngày, máy ra bộ hồ sơ mới: bảng kê số chuyến, bảng kê chi tiết, biên bản xác nhận, giấy đề nghị thanh toán. Giữ nguyên mẫu, định dạng, vùng in. File chỉ xử lý trên máy này.

1 · File hồ sơ thanh toán lần trước Dùng làm mẫu: thông tin hai bên, đơn giá, tuyến đường giữ nguyên.
2 · File số liệu File theo dõi doanh thu tải từ Google Sheet (Tệp → Tải xuống → Microsoft Excel), hoặc file khối lượng 4 cột: Ngày · Biển số · Số chuyến · KL/1 chuyến

Kết quả

  1. Mở file tải về bằng Excel, các ô công thức tự tính lại.
  2. Soát nhanh tổng tiền và số tiền bằng chữ ở biên bản, giấy đề nghị.
  3. In như mọi khi: dòng trống trong bảng kê chi tiết đã được ẩn sẵn.
Công cụ chạy ngay trong trình duyệt, không gửi file đi đâu.
